¿De dónde sale este precio?

Lo que suma o resta cada característica, según lo que aprendió el modelo.

Tres formas de calcularlo

La misma casa con distintos métodos. El error se midió en casas de prueba.

Del dato a la predicción

Lo que hace el programa en Python, paso a paso.

1

Datos

Lee las ventas de casas desde datos/casas.csv.

2

Entrenamiento

Usa el 80 % para aprender con modelo.fit() y guarda el 20 % para comprobar.

3

Predicción

Con lo aprendido calcula el precio de una casa nueva con modelo.predict().

Programación tradicional vs. IA

Tradicional

Una persona escribe la regla.

precio = 30000 * hab

Si el mercado cambia, hay que reescribir el código.

Machine Learning

El modelo descubre la regla con ejemplos.

modelo.fit(X, y)

Si llegan datos nuevos, solo se reentrena.

¿Cuánto acierta cada uno?

Porcentaje del precio que logra explicar (R²) en casas que nunca vio.

Lo que aprendió el modelo

Valores que encontró LinearRegression por sí solo, a partir de los datos.
