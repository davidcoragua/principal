Programación tradicional vs. Inteligencia Artificial

La diferencia clave del tema.

📏 Tradicional

El programador escribe la regla:
precio = 30000 * habitaciones

Si el mercado cambia, hay que reescribir el código a mano.

🤖 Machine Learning

Le damos ejemplos (ventas pasadas) y el modelo descubre la regla:
modelo.fit(X, precios)

Si llegan datos nuevos, solo se reentrena.
